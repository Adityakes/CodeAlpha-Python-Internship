# Hangman Game

A simple text-based Hangman game developed in Python.

## Features

- Random word selection
- 5 predefined words
- Maximum 6 incorrect guesses
- Input validation
- Win/Lose conditions

## Technologies Used

- Python
- Random Module
- Loops
- Conditionals
- Strings
- Lists

## How to Run

1. Install Python.
2. Open terminal in project folder.
3. Run:

```bash
python hangman.py
```
