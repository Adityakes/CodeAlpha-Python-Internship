# 🤖 Basic Rule-Based Chatbot

## 📌 Project Description

The **Basic Rule-Based Chatbot** is a simple Python application that interacts with users by responding to predefined text commands. It uses conditional logic, functions, loops, and dictionaries to provide meaningful responses.

The chatbot can greet users, answer basic questions, tell the current date and time, share programming jokes, and display a list of available commands. It continues the conversation until the user enters an exit command.

---

## 🚀 Features

- 👋 Greets the user with friendly messages
- 💬 Responds to predefined questions
- 📅 Displays the current date
- ⏰ Displays the current time
- 😂 Tells random programming jokes
- 📖 Shows a help menu with available commands
- 🔄 Runs continuously until the user exits
- ❌ Handles unknown commands gracefully
- 🎲 Uses random responses for a better user experience

## 💡 Available Commands

| User Input | Chatbot Response |
|------------|------------------|
| hello | Greets the user |
| hi | Greets the user |
| hey | Greets the user |
| how are you | Replies with its status |
| what is your name | Tells its name |
| who created you | Tells who created it |
| what can you do | Lists its capabilities |
| date | Displays the current date |
| time | Displays the current time |
| joke | Tells a random programming joke |
| thank you | Replies politely |
| thanks | Replies politely |
| help | Displays all available commands |
| bye | Ends the conversation |
