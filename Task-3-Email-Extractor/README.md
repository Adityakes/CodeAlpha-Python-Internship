# Email Address Extractor

## 📌 Description

Email Address Extractor is a simple Python automation project that reads a text file, extracts all valid email addresses using Regular Expressions (Regex), removes duplicate emails, sorts them alphabetically, and saves them into another text file.

This project demonstrates the use of Python file handling, regular expressions, functions, and exception handling.

---

## 🚀 Features

- Read data from a text file
- Extract valid email addresses
- Remove duplicate emails
- Sort email addresses alphabetically
- Save extracted emails into another file
- Display results on the terminal
- Handle missing input files

---

## 🛠 Technologies Used

- Python 3
- Regular Expressions (re)
- File Handling
- Functions
- Exception Handling
